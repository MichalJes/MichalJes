# Hi, I'm Michał

DevOps engineer focused on automation, self-hosted systems, and event tooling.

I like building practical systems that survive real use: tournament operations tools, OBS/event-production workflows, TrueNAS apps, Raspberry Pi appliances, and small domain-specific engines.

## What I work on

- DevOps automation and self-hosted infrastructure
- Event-production tooling for Disney Lorcana tournaments
- Tournament operations software and operator runbooks
- Homelab apps for real household use, not demo screenshots
- Game modding, audio, and small hardware projects

## Current projects

- **DLOP Tournament Alpha:** plain-PHP tournament operations software for Lorcana events: setup editor, readiness gates, rehearsal scripts, export/restore checks, and event-day safety tooling.
- **Lore Vice Lorcana engine:** Rust rules/search/analyzer project with official Ravensburger reference refreshes, CLI analysis reports, bounded replay decoding, and decklist parsing.
- **QuestTourDashboard:** live tournament tooling for Quest Tour and Team Superbrawl events: bracket projection, roster/check-in flows, kiosk readiness, and OBS overlays.
- **Event production stack:** AV/network design for live card-game broadcasts: MikroTik routing, Raspberry Pi/NDI tests, OBS workflows, audio routing, fallback plans, and operator checklists.

## Selected work

**DLOP Tournament Alpha**

Organizer-first tournament platform for a real Lorcana league/event flow. Recent work includes a setup editor, deterministic rehearsal scripts, readiness checks, export verification, and restore-drill hardening.

**Lore Vice Lorcana engine**

Rust workspace for Lorcana rules and analysis experiments. It keeps official rules and API references versioned, separates card metadata from rules support, and is moving toward replay/decklist-based analysis.

**QuestTourDashboard**

Event-day tooling for Disney Lorcana tournaments: roster and check-in support, bracket projection, OBS overlays, and kiosk readiness work for live events.

**Event production stack**

A practical broadcast stack for tabletop events: network planning, camera/audio routing, OBS/NDI experiments, commentator and judge/player communication rigs, and phased hardware validation.

**Ania Bookseerr**

LAN-only ebook catalog/request portal on TrueNAS. Built around a safe Calibre-backed workflow, public-domain imports, ClamD checks, and disabled-by-default broker experiments.

**MeasuringCard**

Master's thesis project: CAN bus EMI measurement card for a Formula Student electric race car, built around STM32, KiCad, and MATLAB.
